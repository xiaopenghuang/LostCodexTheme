# LostCodexTheme v0.2.1

Windows x64 公开预发布修复版。

修复最大化或滚动后，顶部聊天操作按钮仍有黑色方块背景的问题。原因是 Codex 的顶部滚动遮挡样式会给工具栏外层容器刷实色背景，而旧版只将按钮本身设为透明。现在只清除这层容器底色，保留按钮自定义颜色、悬停与按下反馈、原生布局和点击区域。

深色与浅色的安装样式回归覆盖滚动状态切换、窗口尺寸变化、按钮移动、交互和恢复。经用户授权，当前真实窗口的容器背景已验证可变为透明，按钮位置和大小未变；没有重启 Codex。完整实机与安装升级验收仍未完成。

Public preview fix release for Windows x64.

Fixes an opaque square behind the chat-actions button after maximizing or
scrolling. Codex's header edge-scroll styling repaints the toolbar's outer
wrappers even when the buttons themselves are transparent. The adapter now
clears only the wrapper background, preserving configured button colors,
hover/pressed feedback, native geometry, and hit areas.

Dark/light installed-stylesheet regressions cover scroll-state changes, viewport
resizing, action relocation, interaction, and restoration. With the user's
permission, the live wrapper was verified transparent with unchanged geometry
and without restarting Codex. Full live and installer acceptance remain pending.

## Verification / 验证

77 frontend/browser tests, 23 production-editor tests, and 32 Rust tests passed.
Clippy with warnings denied, rustfmt, the release build, and static NSIS
inspection also passed. No installation, upgrade, or full live acceptance was
performed. A targeted live style check confirmed the fix; it is not a complete
compatibility certification.
