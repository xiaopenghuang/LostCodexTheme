# LostCodexTheme v0.2.0

## 中文

首个公开预发布版本，面向 Windows x64。当前版本包含可视化主题编辑、八套预设、本地背景图、独立文字与面板样式、撤销重做、草稿恢复、主题包导入导出及兼容的 Dream Skin 主题转换。右侧文件面板、Outputs/Sources 卡片和顶部工具按钮可在工作面板模块中分别设置。

软件关闭后隐藏到系统托盘，换肤会话继续运行。此次发布统一使用 LCT 软件图标，补充中英文 README、源码开发指南和 MIT 许可证。安装包不依赖 Node.js 或 Rust，界面需要 WebView2 Runtime。

修复了重复应用时主题图层丢失、动态模块映射滞后、应用过程中撤销未生效、取消上传后旧操作覆盖当前主题，以及启动恢复和断线重试后的进程检测问题。Dream Skin 转换同时补充了转义 CSS 外部资源校验。

自动化样式夹具参考 Codex `26.908.4834.0`，不等于该版本的真实窗口兼容认证。真实 Codex 连接、最大化布局、完整恢复及独立 Windows 安装、升级、卸载验收仍待完成，因此本版标为 Pre-release。原生窗口按钮、终端画面和嵌入网页不直接换肤；应用主题会同步并保留 Codex 原生深浅色偏好。

关闭编辑器窗口只会隐藏到托盘。恢复默认或真正退出可能关闭本软件管理的 Codex 会话并请求正常启动，请先保存工作。当前安装包未进行代码签名。

下载附件中的 `LostCodexTheme_0.2.0_x64-setup.exe`，旁边的 `.exe.sha256` 文件用于完整性校验。GitHub 自动生成的 Source code 归档是源码，不是可直接安装的软件。

## English

The first public preview for Windows x64 includes visual theme editing, eight presets, local wallpapers, independent typography and surface controls, undo/redo, draft recovery, theme import/export, and compatible Dream Skin package conversion. Work Panels provides separate controls for the right file panel, Outputs/Sources cards, and header buttons.

Closing the editor keeps the theme session running in the Windows system tray. This release ships unified LCT application branding, Chinese and English READMEs, a development guide, and the MIT license. The packaged app requires WebView2 Runtime, but neither Node.js nor Rust.

Reliability fixes cover detached theme layers on reapply, stale dynamic module mapping, undo during an in-flight apply, cancelled uploads overriding the current document, startup recovery protection, and process-exit detection after reconnect exhaustion. Dream Skin conversion also validates escaped external CSS resource loaders.

Automated stylesheet fixtures reference Codex `26.908.4834.0`; they do not certify live compatibility. Live connection, maximized layouts, full restoration, and installation/upgrade/uninstall acceptance in a disposable Windows environment remain pending. This is therefore a Pre-release. Native caption buttons, terminal rendering, and embedded webpage contents are not directly restyled. Theme application synchronizes Codex's native light/dark preference and retains it after restoration.

Closing the editor window only hides it to the tray. Restore or explicit Exit may close the Codex session managed by this tool before requesting a normal launch. Save your work first. The current installer is not code-signed.

Download `LostCodexTheme_0.2.0_x64-setup.exe` from the release assets and use its `.exe.sha256` companion to verify integrity. GitHub's automatically generated Source code archives are not installers.

The publication build passed 77 frontend/browser tests, 23 production-editor cases, 32 Rust tests, Clippy with warnings denied, formatting, isolated native desktop smoke, and static installer inspection. These checks did not control the running Codex application or execute installation/uninstallation.

Dependency audit found no known npm advisories and no vulnerability entries in the inspected RustSec snapshot. Rust warnings remain for unmaintained dependencies and a glib unsoundness advisory outside the Windows dependency tree. Yanked-crate checks were not performed. These results are not a warning-free security certification.
